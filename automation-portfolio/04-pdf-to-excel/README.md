# 04 · PDF invoices → Excel register

![PDF invoices to Excel](../docs/img/pdf.png)

**Problem:** invoices arrive as PDFs. Every month someone retypes numbers,
dates, tax IDs and totals into a spreadsheet — slowly, with mistakes.

**Solution:** the script reads every PDF in a folder and builds one Excel
register: an **Invoices** sheet with the header fields and a **Line items**
sheet with every line from every invoice, filterable.

## Input → output
- `input/*.pdf` — 3 sample invoices (100% fictional, generated by
  `make_sample_invoices.py`)
- `output/invoice_register.xlsx` — register: 3 invoices, 8 line items,
  total gross 7 848,63 zł

## What the parser handles
- header fields via regex (invoice number, dates, tax IDs, totals)
- **seller/buyer from a two-column layout by coordinates** (`within_bbox` —
  the classic case where plain `extract_text` glues columns together)
- line-item table via `extract_tables`, amounts converted to numbers
- amounts in Excel are numbers — they sum and filter out of the box

## Run it
```bash
python3 make_sample_invoices.py   # generate the sample PDFs (or drop in your own)
python3 extract.py                # build output/invoice_register.xlsx
```

## In a real job
Every issuer has a different template — the parser gets calibrated to **your**
invoices (2–3 samples are enough). The result is always the same clean register.

Tech: Python, pdfplumber, openpyxl (+ reportlab for the samples).
